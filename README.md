# 🖼️ Recortador de Imágenes

Una **PWA** (Progressive Web App) ligera y moderna para recortar imágenes directamente en el navegador. Sin backend, sin subidas a servidores, sin dependencias externas. Todo el procesamiento ocurre localmente en tu dispositivo.

## ✨ Características

- 🎨 **Interfaz clara y moderna** — diseño limpio inspirado en herramientas nativas.
- 📐 **Relaciones de aspecto predefinidas** — más de 20 presets (Video, Fotografía, Hojas, Instagram, Facebook, WhatsApp) y modo **Libre** por defecto.
- ✂️ **Recorte visual con frame arrastrable** — 8 handles para redimensionar, mover el frame, y líneas de tercios para composición.
- 🔍 **Zoom y paneo** — pellizca en Android o usa la rueda del ratón en Windows. La imagen se puede arrastrar para centrarla dentro del frame.
- 🔒 **Frame limitado a la imagen** — el área de recorte nunca se sale de los límites de la imagen cargada.
- 📊 **Dimensiones en vivo** — badge flotante que muestra el tamaño final en píxeles.
- 💾 **Múltiples formatos de salida** — PNG, JPEG, BMP, WebP y AVIF.
- 🎚️ **Calidad ajustable** — slider de 10% a 100% para formatos con pérdida (JPEG, WebP, AVIF).
- 🏷️ **Conservación de metadatos EXIF** — opción para preservar los datos EXIF originales al guardar como JPEG (cámara, fecha, GPS, orientación, etc.).
- 📱 **Instalable como PWA** — añádela al Menú Inicio en Windows o a la pantalla de inicio en Android.
- 🌐 **Funciona offline** — tras la primera carga, el Service Worker cachea todos los recursos.
- 🚫 **100% local** — ninguna imagen sale de tu dispositivo. No hay servidores, no hay telemetría.
